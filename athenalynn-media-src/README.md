# Homepage stand-in artwork

Every image in `athenalynn-site/media/` is original artwork drawn in code by `render.cjs`.
It contains no photography or third-party assets. These are stand-ins until commissioned
photography or film is available.

    node render.cjs <outDir>    # renders WebP files; then resize/copy into athenalynn-site/media

| File | Used for |
|---|---|
| hero-wall-l / hero-wall-p | Opening: limestone wall (landscape / portrait) |
| hero-sun-l / hero-sun-p | Opening: sunlight through two arched openings (also the mask for the palm shadows) |
| hero-fronds-far / hero-fronds-near | Opening: palm-frond shadows, animated in CSS |
| grain | Opening: film grain overlay |
| oversee-* | "What I oversee": one image per area |
