Invitational Draw

Set each club's spots, press Run draw, and see who goes where. The same draw code always gives the same result, so anyone can check it.

How the draw works

  1. Home-event players first. Members playing in the Queen Bee Invitational are placed before everyone else.
  2. Random order within each group, set by the draw code.
  3. Everyone gets one before anyone gets two. Each member gets her highest-ranked club with a spot open.
  4. Later rounds run in reverse order, so nobody is always last.
  5. Open spots go to members who'll take an alternate club within their drive area.
  6. Everyone else who ranked a club becomes its alternates, in draw order.

Settings

Change any setting and the results below update. Nothing here affects real members; it's a way to try out the rules before we agree on them.

Spots at each club

Spots is how many Eastpointe members each club will take. Alternates is how many back-up names the club wants, in case someone drops out. Change a number to see how a bigger or smaller allotment affects who gets in.
